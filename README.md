☁️ Deployment Process
1.Created/launched a Windows Server EC2 instance on AWS.
2.Connected to the Windows server using Remote Desktop (RDP).
3.Installed Web Server (IIS) using Server Manager.
4.Opened IIS Manager and configured the website.
5.Copied the website files into:
`C:\\inetpub\\wwwroot`
Started the IIS Default Web Site.
Tested the website using the EC2 Public IPv4 address.
Confirmed that the Sarab website was accessible in the browser.
